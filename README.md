# ツイート削除ユーティリティ v1.0

X（旧Twitter）のタイムラインから、ツイート・RT・お気に入りを自動削除するブックマークレットです。

---

## 使い方

1. `temp_code.js` の内容をすべてコピーする
2. ブラウザのブックマークバーを右クリック →「ページを追加」
3. 名前を任意で入力し、URL欄にコピーした内容を貼り付けて保存
4. X のタイムラインページ（自分のプロフィールページ等）を開いた状態でブックマークをクリック
5. 設定ダイアログが表示されるので、条件を指定して「実行する(E)」

---

## 設定項目

### 削除対象の選択
削除するコンテンツの種別をチェックボックスで選択します。

| 項目 | 内容 |
|---|---|
| 自分のツイート | 自分が投稿したツイートを削除 |
| RT（リツイート） | リツイートした投稿を取り消し |
| お気に入り（いいね） | いいねした投稿を解除 |

### 削除対象キーワード（優先）
指定したキーワードを含むツイートを**優先的に削除**します。

- カンマ区切りで複数指定可能（例：`コメント,宣伝,PR`）
- このフィールドに入力した場合、**マッチしたツイートのみを削除対象**とします
- 保護条件（下記）よりも優先されます
- 空欄の場合：この条件は無効、通常の全件削除モードで動作します

### 保護キーワード（削除除外）
指定したキーワードを含むツイートを**削除しません**。

- カンマ区切りで複数指定可能
- 削除対象キーワードが未設定の場合のみ有効（削除対象キーワードが優先）
- 空欄の場合：この条件は無効

### お気に入り数による保護
指定した件数以上のお気に入りが付いているツイートを**削除しません**。

- 0のままにすると、この条件は無効
- 削除対象キーワードが未設定の場合のみ有効

### ツイートIDによる保護
特定のツイートIDを指定して**削除対象から除外**します。

- カンマ区切りで複数指定可能
- ツイートIDはツイートURLの末尾の数字（例：`https://x.com/user/status/1234567890123456789` → `1234567890123456789`）
- 削除対象キーワードが未設定の場合のみ有効

---

## 保護条件の優先順位

```
削除対象キーワード（設定時）
  ├─ マッチする  → 保護条件をすべて無視して削除
  └─ マッチしない → スキップ（削除しない）

削除対象キーワード（未設定時）
  → ツイートID保護 → 保護キーワード → お気に入り数 → 削除
```

## 安全機能

### タイミングのランダム化（凍結・bot判定対策）
- 各アクション後に **2〜8秒** のランダム待機を挿入
- **50件到達時**：2〜3分の短期休止（カウントダウン表示）
- **200件到達時**：10〜15分の長期休止（カウントダウン表示）
- **500件到達時**：1日の規制ラインに接触しないよう自動停止しアラートを表示

### 人間らしい操作の模倣（20%確率）
1ループごとに20%の確率で、削除を行わずにスクロール閲覧の挙動をエミュレートします。

### 誤操作防止シールド
実行中は画面全体に半透明のオーバーレイを展開し、背後のタイムラインへの誤クリックを防ぎます。

### 画面スリープ防止
`navigator.wakeLock` API により、実行中に画面が暗転・スリープしてスクリプトが停止するのを防ぎます。

---

## 実行中の画面

シールド中央にステータスボードが表示されます。

| 表示 | 内容 |
|---|---|
| 削除済み件数 | 現在までに処理したアクション数 |
| メッセージ欄 | 現在の処理状況・休止残り時間 |
| 中断する(S) | クリックで処理を安全に停止 |

---

## 注意事項

- 削除したツイートは**復元できません**。実行前に設定内容を必ず確認してください
- 実行前に確認ダイアログが表示されます。設定内容を見直してから「OK」を押してください
- X のDOM構造変更により、将来的に動作しなくなる場合があります
- 本ツールの使用により生じたいかなる損害についても、作者は責任を負いません
